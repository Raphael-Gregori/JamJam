# JamJam
a Jam between worlds

## Concept combat

- Combat 2D
- Système de "lignes" : corps divisé en zones (ex: tête, torse, jambes...)
- Chaque joueur envoie une attaque sur une ligne
- Résultat = confrontation ligne vs ligne (soi vs adversaire)
- Par-dessus : stats RPG classiques (HP, dégâts, etc.)
- But : battre l'adversaire
